# 定力台 · 单文件 H5 自律工作台

> 把自律变成看得见的进度 —— 每日任务、番茄钟、App 限时、时间兑换、专注森林，全部装进一个 HTML 文件。

**定力台** 是一个**纯前端、单文件**的自律 / 习惯养成工作台。打开 `index.html` 即用，无需后端、无需联网（联网仅用于首次加载后的离线缓存）。数据全部存在你设备的浏览器 `localStorage` 里，不经过任何服务器。

## 功能特性

- **行为内核**：微习惯（最小一步 `|` 语法 + ⚓ 锚点）、即时庆祝动效、弹性补卡、时间兑换（25 分钟专注 → +10 分钟娱乐额度）、打开娱乐 App 前的「呼吸摩擦」停顿。
- **锁机联动**：页内全屏沉浸锁机，支持「锁 25/45 分钟」「完成 1 个番茄解锁」「任务全清才解锁」；切走会被计入失败。
- **可视化 & 成长**：专注森林（每完成一次专注种一棵树）、年度热力图、专注分、睡前灰阶 + 锁娱乐。
- **健康 & 体验**：程序化白噪音（静 / 白 / 雨 / 海 / 林，WebAudio 合成，无需音频文件）；浅色 / 深色主题切换；finesse-ui 玻璃拟态 + 光晕美化。
- **PWA**：可「添加到主屏幕」当独立 App 使用，且离线可用。

## 本地运行

直接双击 `index.html` 用浏览器打开即可。若想触发 PWA / Service Worker（推荐），用本地静态服务器：

```bash
# 任选其一，在仓库目录下执行
python -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080`。

## 诚实边界

- 这是**网页 App**，能做的「锁机」是页内全屏沉浸 + 离开二次确认，**不是系统级强锁**——关掉浏览器标签页就停了。真正的跨 App 强锁需要原生应用，H5 做不到。
- 数据在**本机浏览器**，换手机不跟随，需重新规划。
